# ClimaPro — pacote de teste

Este pacote contém o código-fonte atual do ClimaPro.

## Preparação

1. Instale Node.js 20 ou superior.
2. Execute `npm install`.
3. Copie `.env.example` para `.env.local`.
4. Preencha as credenciais do Supabase.
5. Execute `npm run dev`.

**Importante:** esta versão ainda depende da configuração do Supabase para autenticação e dados. Ela não deve ser considerada uma versão final de produção.
